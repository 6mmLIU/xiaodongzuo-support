小动作 Twiddly 隐私政策（TapTap 版）

更新及生效日期：2026 年 10 月 23 日；版本：2026-10-23-v1。

本政策适用于安卓 TapTap 广告版，开发者为刘昊明，联系邮箱：haomiliu04@gmail.com。

1. 本地游戏与广告

15 个玩具全部免费。玩具、音效、震动、主题、计数和设置在设备本地运行及保存，无需创建游戏账号。重力滚珠使用设备加速度传感器，数据仅用于本地物理模拟，不发送给广告 SDK。

我们使用 TapADN SDK 展示启动时的开屏广告。首次运行时由你选择是否同意广告相关数据处理；未同意前不初始化或请求广告 SDK。你可以选择“不同意，直接玩”，继续使用全部本地玩具。无广告填充、断网或加载超时时直接进入游戏。

2. 第三方 SDK 与处理范围

SDK 名称：TapADN SDK，版本 5.3.0.4。提供方：上海艾得蒽数字科技有限公司及其关联方。目的：广告展示、投放统计、监测归因、反作弊、崩溃及性能分析。方式：你同意后，SDK 自行采集并向服务方传输必要信息。

必要处理可能包括 IP 地址、设备品牌和型号、操作系统版本、屏幕密度和分辨率、设备语言和时区、CPU 和可用存储信息、网络状态、应用包名和版本、应用前后台状态、广告展示/点击/转化信息、崩溃和性能信息。具体以 SDK 提供方的政策和实际运行情况为准。

本版本主动关闭 SDK 的位置、电话状态/序列号、Wi-Fi 信息（包括 SSID、BSSID、MAC）、应用安装列表、Android ID、OAID、传感器及外部存储访问；不申请定位、电话、应用安装或全量软件列表权限，不启用摇一摇跳转。关闭这些可选信息可能影响广告填充。

SDK 的完整规则、保存期限、安全措施及权利行使方式请阅读：TapADN SDK 隐私政策；官网：ssp.dirichlet.cn。

3. 个性化广告

个性化广告默认关闭。你可以在“隐私与广告设置”中单独开启或关闭。关闭后仍可能看到普通广告，广告数量不因该开关而减少。

4. 撤回与删除

首页底部“隐私与广告设置”可撤回广告授权，撤回后立即结束本应用的广告展示及等待过程，不再发起新的广告请求；下次启动不初始化广告 SDK。已发送给服务方的信息可通过上述 SDK 政策提供的方式，或联系开发者申请查阅、复制、更正、删除。卸载或清除本应用数据可删除本地设置及记录。

5. 未成年人

未成年人请在监护人指导下阅读本政策。不满 14 周岁者请由监护人决定是否同意广告相关处理；未获同意时可选择不同意并使用本地玩具。本应用不是医疗产品，不用于诊断或治疗 ADHD 或其他疾病。

6. 政策更新

处理目的或范围发生实质变化时，我们将更新政策版本并重新征求同意。对本政策或个人信息处理有疑问，请联系 haomiliu04@gmail.com。
